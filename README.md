# Kenzo – GitHub Pages

Valmis ühe-leheline mobiilisõbralik Kenzo QR-koodi leht.

## Failid

- `index.html` – lehe sisu
- `styles.css` – kujundus
- `script.js` – GPS-asukoha küsimine ja valmis SMS-i avamine
- `kenzo-hero.webp` – Kenzo hero-pilt
- `og.png` – Facebooki / Messengeri / WhatsAppi eelvaatepilt
- `favicon.svg` – brauseri ikoon

## GitHub Pages

Kui repo nimi on `kenzo` ja kasutaja `g0apele`, on avalik aadress:

`https://g0apele.github.io/kenzo/`

GitHubis:
1. Lae need failid repo juurkausta.
2. Ava **Settings → Pages**.
3. Source: **Deploy from a branch**.
4. Branch: **main**, folder: **/(root)**.
5. Salvesta.

Kui Pages on seadistatud avaldama `docs` kausta, tõsta kõik need failid `docs/` kausta.
