# Kenzo

QR-koodist avanev mobiilisõbralik lehekülg Kenzo kohta.

Leht annab skannijale teada, et Kenzo ei ole kadunud, selgitab tema tavapärast
Taara/Kruusa tänava piirkonda ning võimaldab saata Kenzo inimesele SMS-i koos
vabatahtlikult jagatud Google Mapsi asukohalingiga.

GitHub Pages avaldab kausta [`docs`](docs).
